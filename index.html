Passo 1 — Instalar e Configurar o Arduino IDE

Configure o ambiente de desenvolvimento antes de conectar qualquer hardware.

ℹ️
Este projeto usa ledcAttach/ledcWrite do ESP32 Arduino SDK 3.0+. Instale a versão 3.0.0 ou superior — versões antigas usam API diferente e o código não compila.
1/3 — Instalar Arduino IDE e pacote ESP32
Baixar e instalar o Arduino IDE 2.x
Acesse arduino.cc/en/software → baixe a versão 2.x para Windows → execute o instalador.
File → Preferences → colar a URL do ESP32 em "Additional boards manager URLs"
URL no painel direito. Cole e clique OK.
Tools → Board → Boards Manager → pesquisar "esp32" → instalar "esp32 by Espressif Systems"
Selecione versão ≥ 3.0.0 antes de instalar. A instalação demora alguns minutos.
Tools → Board → esp32 → selecionar "NodeMCU-32S"
Alternativa: "ESP32 Dev Module". Funciona igualmente para este projeto.
2/3 — Instalar biblioteca do controle Xbox
Tools → Manage Libraries (Ctrl+Shift+I) → pesquisar "XboxSeriesX"
O Library Manager abre na lateral esquerda do IDE 2.x.
Instalar "XboxSeriesXControllerESP32_asukiaaa" (autor: asukiaaa)
Se pedir para instalar dependências, clique "Install All".
3/3 — Carregar o sketch e testar
File → Open → abrir hovercomesp32D0WDQ6.ino
Navegue até a pasta do projeto e abra o arquivo .ino.
Conectar o ESP32 via USB e selecionar a porta: Tools → Port → COM?
Se a porta não aparecer, instale o driver CP210x ou CH340 conforme o chip USB do seu NodeMCU.
Clicar em Verify (✓) para compilar — deve aparecer "Done compiling"
Erros de compilação geralmente indicam versão errada do SDK. Confirme que está usando esp32 ≥ 3.0.0.
Clicar em Upload (→) e aguardar — LED do ESP32 pisca durante o upload
Após upload, o ESP32 reinicia automaticamente e executa o código.
Abrir Monitor Serial (Tools → Serial Monitor) → selecionar 115200 baud
Deve aparecer "--- CONFIGURANDO SENTIDO: CIMA = FRENTE ---". Ambiente OK!
✅
Compilou e o Monitor Serial mostrou a mensagem? Ambiente configurado! Monte o hardware nos próximos passos.

Passo 2 — Ligar apenas o ESP32

Monte a fonte 5V antes de conectar qualquer driver. Teste e valide antes de continuar.

V1Versão Simples — sem diodo nem capacitor
🚫
NÃO conecte 24V diretamente ao ESP32. Use o MP1584 para converter para 5V.
⚠️
Ajuste o MP1584 com voltímetro sem o ESP32 conectado até marcar 5.0V. Sem o diodo: confirme sempre a polaridade antes de energizar.
Conexões V1 — 4 ligações
Bat+ 24V → MP1584 INPUT+
Fio vermelho. Positivo direto no buck. Confirme a polaridade!
Bat− → MP1584 INPUT−
Fio preto. GND unificado de todo o sistema.
MP1584 OUTPUT+ → ESP32 pino 5V0
Fio laranja. Saída 5V regulada vai ao pino 5V0 — último pino, lado esquerdo da placa.
MP1584 OUTPUT− → ESP32 pino GND
Fio preto. Qualquer pino GND da placa.
Fluxo V1
Bat+ 24V→MP1584 IN+ (direto)
Bat− GND→MP1584 IN− = GND
MP1584 OUT+ 5V→ESP32 5V0
MP1584 Out− GND→ESP32 GND
V2Versão Protegida — com diodo N04 e capacitor 1000µF
🚫
NÃO conecte 24V diretamente ao ESP32. Use o MP1584 para converter para 5V.
⚠️
Ajuste o MP1584 com voltímetro sem o ESP32 conectado até marcar 5.0V.
Conexões V2 — 7 ligações
Bat+ 24V → Diodo N04 (anodo — lado sem faixa)
Fio vermelho. Lado sem marca = anodo (entrada). Faixa cinza = catodo (saída).
Diodo N04 (catodo — faixa) → MP1584 INPUT+
Proteção de polaridade: bateria ao contrário → diodo bloqueia → circuito protegido.
Bat− → MP1584 INPUT−
Fio preto. GND unificado.
MP1584 OUTPUT+ → polo (+) do capacitor 1000µF
Fio laranja. Perna mais longa = positivo. Filtra ruídos dos motores.
MP1584 OUTPUT− → polo (−) do capacitor → GND
Fio preto. Fecha o circuito do capacitor no GND.
Polo (+) do capacitor → ESP32 pino 5V0
Fio laranja. Use o pino 5V0 — último pino, lado esquerdo da placa.
GND unificado → ESP32 pino GND
Fio preto. Qualquer pino GND da placa.
Fluxo V2
Bat+ 24V→Diodo N04 → MP1584 IN+
Bat− GND→MP1584 IN− = GND
MP1584 OUT+ 5V→Cap (+) → ESP32 5V0
MP1584 Out− GND→Cap (−) → ESP32 GND

Passo 3 — Motor Esquerdo (Driver 1)

GPIO 12 (avança) e GPIO 14 (recua) controlam o motor esquerdo. Desligue a bateria antes de conectar.

ℹ️
Desligue a bateria antes de qualquer conexão. Religue só após verificar tudo.
Alimentação de potência — Driver 1 (24V)
Bat+ 24V → Driver 1 VM+ (borne parafuso, pino 11)
Fio vermelho GROSSO. Use fio ≥ 1,5mm².
GND unificado → Driver 1 VM− (borne parafuso, pino 12)
Fio preto GROSSO. Mesmo barramento de GND da bateria.
Lógica de controle — Driver 1 (header 8 pinos)
MP1584 OUT+ → Driver 1 VCC (pino 7)
Fio laranja. Ramal direto do MP1584, paralelo ao fio do ESP32 5V0.
ESP32 GND → Driver 1 GND (pino 8)
Fio preto. CRÍTICO: sem este fio o driver não recebe os sinais do ESP32.
ESP32 pino 3V3 → Driver 1 R_EN (pino 3)
Fio amarelo. Enable permanente do lado R.
ESP32 pino 3V3 → Driver 1 L_EN (pino 4)
Pode ramificar do mesmo fio do R_EN.
ESP32 GPIO 12 → Driver 1 R_PWM (pino 1)
Fio azul. Controla AVANÇAR. GPIO 12 fica no lado direito da placa.
ESP32 GPIO 14 → Driver 1 L_PWM (pino 2)
Fio verde. Controla RECUAR. GPIO 14 fica no lado direito da placa.
Motor Esquerdo → Driver 1
Motor Esq. Fio A → Driver 1 Motor+ (pino 10)
Inverter se girar ao contrário do esperado.
Motor Esq. Fio B → Driver 1 Motor− (pino 9)

Passo 5 — Receptor FS-iA6B (Modo Rádio)

Conexão do receptor FS-iA6B ao ESP32 via protocolo iBUS. Opcional — só se for usar o rádio FS-i6X.

ℹ️
Este passo é opcional. Se for usar apenas o Xbox, pule para o Passo 6. O código já suporta os dois modos — o que conectar primeiro vira o controle ativo.
⚠️
Antes de conectar, configure o protocolo iBUS no FS-i6X: System → RX Setup → Protocol → iBUS. Sem isso o receptor não envia dados válidos.
Alimentação do FS-iA6B
MP1584 OUT+ → FS-iA6B pino + (B/VCC)
Fio laranja. Ramal direto do MP1584, paralelo ao fio do ESP32 5V0 e dos drivers.
ESP32 GND → FS-iA6B pino − (B/VCC)
Fio preto. GND comum.
Sinal iBUS
FS-iA6B porta i-BUS (SENS) → ESP32 GPIO 13
Fio roxo. Pino Signal da porta SENS do conector i-BUS. GPIO 13 = UART1 RX.
Mapeamento de canais (configurar no FS-i6X)
■ CH1 — Stick esq. horizontal → Virar (steering)
■ CH2 — Stick esq. vertical → Frente / Ré (throttle)
■ CH6 — Chave SwC (3 posições) → Pistão da lâmina: cima=abre, meio=parado, baixo=fecha
■ CH7 — Chave SwA ou SwD → Lâmina ON/OFF
■ CH10 — Chave SwD → HABILITAÇÃO + EMERGÊNCIA — opere com SwD em ON (2000); SwD em OFF ou rádio desligado = trava tudo
Atribua em Menu → Functions → Aux. channels: Channel 6 = SwC, Channel 7 = SwA, Channel 10 = SwD. (CH9 não serve de sentinela neste rádio: ele espelha a SwA. Canal None não grava failsafe — por isso o CH10 usa a SwD.)
⚠️ Failsafe — obrigatório (Menu → System → RX Setup → Failsafe)
Com o transmissor desligado, o FS-iA6B continua enviando os últimos valores via iBUS — sem failsafe configurado, motores e pistão continuam executando o último comando indefinidamente. Configure (deixe o controle na posição segura e salve):
■ CH2 = 0% (stick no centro) → tração para
■ CH6 = 0% (SwC no meio) → pistão para
■ CH7 = −100% (chave em OFF) → lâmina desliga
■ CH10 = −100% (SwD desligada) → rádio caiu envia CH10=1000 e o código trava tudo (corta TODA a energia do braço, para motores, desliga a lâmina, desarma e bloqueia rearme)
Regra de ouro: grave o failsafe com os sticks no centro e TODAS as chaves desligadas — nessa condição todos os canais ficam corretos de uma vez.
⚠️ Atenção ao salvar o CH7: a chave SwA precisa estar em OFF no momento de salvar — se salvar com ela em ON (+100%), desligar o rádio LIGA a lâmina!
Teste: com o braço em movimento e a lâmina ligada, desligue o transmissor — tudo deve parar imediatamente e o Serial deve exibir [!] FAILSAFE — radio desligado!
MP1584 OUT+ 5V→FS-iA6B B/VCC pino + (ramal paralelo)
ESP32 GND→FS-iA6B B/VCC pino −
FS-iA6B i-BUS SENS Signal→ESP32 GPIO 13

#include <XboxSeriesXControllerESP32_asukiaaa.hpp>
// iBUS implementado internamente — sem biblioteca externa

// ─── LEITOR iBUS (FlySky FS-iA6B) ───────────────────────────────────────────
struct IBusSimple {
  uint16_t ch[14] = {};
  unsigned long lastPacketMs = 0;

  void update(HardwareSerial& s) {
    static uint8_t buf[32];
    static uint8_t pos = 0;
    while (s.available()) {
      uint8_t b = s.read();
      if (pos == 0 && b != 0x20) continue;
      if (pos == 1 && b != 0x40) { pos = 0; continue; }
      buf[pos++] = b;
      if (pos == 32) {
        pos = 0;
        uint16_t sum = 0;
        for (int i = 0; i < 30; i++) sum += buf[i];
        uint16_t ck = buf[30] | ((uint16_t)buf[31] << 8);
        if (ck == (uint16_t)(0xFFFF - sum)) {
          for (int i = 0; i < 14; i++)
            ch[i] = buf[2 + i*2] | ((uint16_t)(buf[3 + i*2] & 0x0F) << 8);
          lastPacketMs = millis();
        }
      }
    }
  }
  uint16_t readChannel(int c) { return (c >= 0 && c < 14) ? ch[c] : 0; }
  bool signalLost(unsigned long ms = 500) { return (millis() - lastPacketMs) > ms; }
};

// --- PINOS ---
const int MOTOR_ESQ_RPWM = 12, MOTOR_ESQ_LPWM = 14;
const int MOTOR_DIR_RPWM = 16, MOTOR_DIR_LPWM = 17;
const int MOTOR_LAMINA = 23, LED_PIN = 2, IBUS_RX = 13;
const int PISTON_RPWM = 25, PISTON_LPWM = 26; // BTS7960 do atuador linear

// --- MODOS ---
enum ControlMode { WAITING, XBOX, RADIO };
ControlMode mode = WAITING;

XboxSeriesXControllerESP32_asukiaaa::Core xboxController;
IBusSimple ibus;
HardwareSerial ibusSerial(1);

const int PWM_MAX = 220;
const int PISTON_PWM = 220;
bool armed = false;
unsigned long armStartMs = 0;
const unsigned long ARM_HOLD_MS = 1000;

void setup() {
  Serial.begin(115200);
  delay(1000);
  ledcAttach(MOTOR_ESQ_RPWM, 5000, 8); ledcAttach(MOTOR_ESQ_LPWM, 5000, 8);
  ledcAttach(MOTOR_DIR_RPWM, 5000, 8); ledcAttach(MOTOR_DIR_LPWM, 5000, 8);
  ledcAttach(PISTON_RPWM, 5000, 8); ledcAttach(PISTON_LPWM, 5000, 8);
  desenergizar_pistao(); // sem rádio = nenhuma energia no atuador
  pinMode(MOTOR_LAMINA, OUTPUT); digitalWrite(MOTOR_LAMINA, LOW);
  pinMode(LED_PIN, OUTPUT);
  ibusSerial.begin(115200, SERIAL_8N1, IBUS_RX, -1);
  xboxController.begin();
  Serial.println("[AGUARDANDO] Ligue o radio FS-i6X ou conecte o Xbox...");
}

void loop() {
  atualizarLed();
  switch (mode) {
    case WAITING: loopWaiting(); break;
    case XBOX:    loopXbox();    break;
    case RADIO:   loopRadio();   break;
  }
}

void loopWaiting() {
  desenergizar_pistao(); // garante 0V no atuador sem controle ativo
  xboxController.onLoop();
  if (xboxController.isConnected()) { mode = XBOX; return; }
  ibus.update(ibusSerial);
  uint16_t ch1 = ibus.readChannel(0), ch2 = ibus.readChannel(1);
  if (!ibus.signalLost(300) && ch1 >= 900 && ch1 <= 2100 && ch2 >= 900 && ch2 <= 2100
      && ibus.readChannel(9) >= 1700) { // só entra com SwD ligada (habilitado)
    mode = RADIO;
    Serial.println("[MODO] Radio FS-i6X conectado!");
  }
  delay(10);
}

void loopXbox() {
  xboxController.onLoop();
  if (!xboxController.isConnected()) { parar_motores(); desenergizar_pistao(); digitalWrite(MOTOR_LAMINA, LOW); mode = WAITING; return; }
  if (xboxController.isWaitingForFirstNotification()) return;
  int32_t joyY = 32768 - (int32_t)xboxController.xboxNotif.joyLVert;
  int32_t joyX = (int32_t)xboxController.xboxNotif.joyLHori - 32768;
  if (abs(joyY) < 3500) joyY = 0;
  if (abs(joyX) < 3500) joyX = 0;
  int esq = map(joyY + (joyX/2), -32768, 32767, -PWM_MAX, PWM_MAX);
  int dir = map(joyY - (joyX/2), -32768, 32767, -PWM_MAX, PWM_MAX);
  digitalWrite(MOTOR_LAMINA, xboxController.xboxNotif.trigRT > 512 ? HIGH : LOW);
  acionarMotores(esq, dir);
}

void loopRadio() {
  ibus.update(ibusSerial);
  uint16_t ch1 = ibus.readChannel(0), ch2 = ibus.readChannel(1);
  uint16_t ch6 = ibus.readChannel(5), ch7 = ibus.readChannel(6);
  uint16_t ch10 = ibus.readChannel(9); // sentinela de failsafe

  // TRAVA: operar exige SwD ON (CH10 ≈ 2000). Rádio caiu → failsafe 1000;
  // SwD OFF = kill manual. Qualquer um corta toda a energia.
  if (ch10 < 1700) {
    Serial.println("[!] TRAVA — SwD desligada ou radio caiu!");
    parar_motores(); desenergizar_pistao(); digitalWrite(MOTOR_LAMINA, LOW);
    ibus.lastPacketMs = 0; armed = false; armStartMs = 0; mode = WAITING;
    return;
  }

  if (ibus.signalLost() || ch1 < 900 || ch1 > 2100 || ch2 < 900 || ch2 > 2100) {
    Serial.println("[!] Sinal perdido — parando");
    parar_motores(); desenergizar_pistao(); digitalWrite(MOTOR_LAMINA, LOW);
    ibus.lastPacketMs = 0; armed = false; armStartMs = 0; mode = WAITING;
    return;
  }

  // Armação: throttle no mínimo (CH2 ≤ 1050) por 1s
  if (!armed) {
    if (ch2 <= 1050) {
      if (armStartMs == 0) armStartMs = millis();
      if (millis() - armStartMs >= ARM_HOLD_MS) {
        armed = true; armStartMs = 0;
        Serial.println("[ARM] Sistema armado — controle ativo!");
      }
    } else { armStartMs = 0; }
    parar_motores(); desenergizar_pistao(); digitalWrite(MOTOR_LAMINA, LOW); return;
  }

  // Operação normal
  int throttle = (int)ch2 - 1500, steering = (int)ch1 - 1500;
  if (abs(throttle) < 50) throttle = 0;
  if (abs(steering) < 50) steering = 0;
  int esq = constrain(map(throttle + (steering/2), -500, 500, -PWM_MAX, PWM_MAX), -PWM_MAX, PWM_MAX);
  int dir = constrain(map(throttle - (steering/2), -500, 500, -PWM_MAX, PWM_MAX), -PWM_MAX, PWM_MAX);
  // Pistão (SwC): cima = abre | meio = parado | baixo = fecha
  // Comportamento real do braço: saída 0 = abre | +220 = parado | -220 = fecha
  int pistao = PISTON_PWM;
  if (ch6 < 1200) pistao = 0;
  else if (ch6 > 1800) pistao = -PISTON_PWM;
  digitalWrite(MOTOR_LAMINA, ch7 > 1500 ? HIGH : LOW);
  acionarMotores(esq, dir);
  acionarPistao(pistao);
}

void atualizarLed() {
  unsigned long now = millis();
  switch (mode) {
    case WAITING: digitalWrite(LED_PIN, (now/500)%2==0 ? HIGH:LOW); break;
    case XBOX:    digitalWrite(LED_PIN, HIGH); break;
    case RADIO:
      if (!armed) { digitalWrite(LED_PIN, (now/100)%2==0 ? HIGH:LOW); }
      else { unsigned long t=now%1000; digitalWrite(LED_PIN, (t<100||(t>=200&&t<300)) ? HIGH:LOW); }
      break;
  }
}

void acionarMotores(int v_esq, int v_dir) {
  ledcWrite(MOTOR_ESQ_RPWM, v_esq>=0 ? abs(v_esq):0); ledcWrite(MOTOR_ESQ_LPWM, v_esq<0 ? abs(v_esq):0);
  ledcWrite(MOTOR_DIR_RPWM, v_dir>=0 ? abs(v_dir):0); ledcWrite(MOTOR_DIR_LPWM, v_dir<0 ? abs(v_dir):0);
}
void parar_motores() {
  ledcWrite(MOTOR_ESQ_RPWM,0); ledcWrite(MOTOR_ESQ_LPWM,0);
  ledcWrite(MOTOR_DIR_RPWM,0); ledcWrite(MOTOR_DIR_LPWM,0);
}

void acionarPistao(int v) {
  if (v > 0) { ledcWrite(PISTON_RPWM, v); ledcWrite(PISTON_LPWM, 0); }
  else if (v < 0) { ledcWrite(PISTON_RPWM, 0); ledcWrite(PISTON_LPWM, abs(v)); }
  else { ledcWrite(PISTON_RPWM, 0); ledcWrite(PISTON_LPWM, 0); }
}

void desenergizar_pistao() {
  // Corta TODA a energia do atuador (0/0). Sem rádio ou desarmado.
  // Atenção: sem energia o braço tende a ABRIR (característica do braço).
  ledcWrite(PISTON_RPWM, 0); ledcWrite(PISTON_LPWM, 0);
}
