Passo 1 — Instalar e Configurar o Arduino IDE

Configure o ambiente de desenvolvimento antes de conectar qualquer hardware.

ℹ️
Este projeto usa ledcAttach/ledcWrite do ESP32 Arduino SDK 3.0+. Instale a versão 3.0.0 ou superior — versões antigas usam API diferente e o código não compila.
1/3 — Instalar Arduino IDE e pacote ESP32
Baixar e instalar o Arduino IDE 2.x
Acesse arduino.cc/en/software → baixe a versão 2.x para Windows → execute o instalador.
File → Preferences → colar a URL do ESP32 em "Additional boards manager URLs"
URL no painel direito. Cole e clique OK.
Tools → Board → Boards Manager → pesquisar "esp32" → instalar "esp32 by Espressif Systems"
Selecione versão ≥ 3.0.0 antes de instalar. A instalação demora alguns minutos.
Tools → Board → esp32 → selecionar "NodeMCU-32S"
Alternativa: "ESP32 Dev Module". Funciona igualmente para este projeto.
2/3 — Instalar biblioteca do controle Xbox
Tools → Manage Libraries (Ctrl+Shift+I) → pesquisar "XboxSeriesX"
O Library Manager abre na lateral esquerda do IDE 2.x.
Instalar "XboxSeriesXControllerESP32_asukiaaa" (autor: asukiaaa)
Se pedir para instalar dependências, clique "Install All".
3/3 — Carregar o sketch e testar
File → Open → abrir hovercomesp32D0WDQ6.ino
Navegue até a pasta do projeto e abra o arquivo .ino.
Conectar o ESP32 via USB e selecionar a porta: Tools → Port → COM?
Se a porta não aparecer, instale o driver CP210x ou CH340 conforme o chip USB do seu NodeMCU.
Clicar em Verify (✓) para compilar — deve aparecer "Done compiling"
Erros de compilação geralmente indicam versão errada do SDK. Confirme que está usando esp32 ≥ 3.0.0.
Clicar em Upload (→) e aguardar — LED do ESP32 pisca durante o upload
Após upload, o ESP32 reinicia automaticamente e executa o código.
Abrir Monitor Serial (Tools → Serial Monitor) → selecionar 115200 baud
Deve aparecer "--- CONFIGURANDO SENTIDO: CIMA = FRENTE ---". Ambiente OK!
✅
Compilou e o Monitor Serial mostrou a mensagem? Ambiente configurado! Monte o hardware nos próximos passos.

Passo 2 — Ligar apenas o ESP32

Monte a fonte 5V antes de conectar qualquer driver. Teste e valide antes de continuar.

V1Versão Simples — sem diodo nem capacitor
🚫
NÃO conecte 24V diretamente ao ESP32. Use o MP1584 para converter para 5V.
⚠️
Ajuste o MP1584 com voltímetro sem o ESP32 conectado até marcar 5.0V. Sem o diodo: confirme sempre a polaridade antes de energizar.
Conexões V1 — 4 ligações
Bat+ 24V → MP1584 INPUT+
Fio vermelho. Positivo direto no buck. Confirme a polaridade!
Bat− → MP1584 INPUT−
Fio preto. GND unificado de todo o sistema.
MP1584 OUTPUT+ → ESP32 pino 5V0
Fio laranja. Saída 5V regulada vai ao pino 5V0 — último pino, lado esquerdo da placa.
MP1584 OUTPUT− → ESP32 pino GND
Fio preto. Qualquer pino GND da placa.
Fluxo V1
Bat+ 24V→MP1584 IN+ (direto)
Bat− GND→MP1584 IN− = GND
MP1584 OUT+ 5V→ESP32 5V0
MP1584 Out− GND→ESP32 GND
V2Versão Protegida — com diodo N04 e capacitor 1000µF
🚫
NÃO conecte 24V diretamente ao ESP32. Use o MP1584 para converter para 5V.
⚠️
Ajuste o MP1584 com voltímetro sem o ESP32 conectado até marcar 5.0V.
Conexões V2 — 7 ligações
Bat+ 24V → Diodo N04 (anodo — lado sem faixa)
Fio vermelho. Lado sem marca = anodo (entrada). Faixa cinza = catodo (saída).
Diodo N04 (catodo — faixa) → MP1584 INPUT+
Proteção de polaridade: bateria ao contrário → diodo bloqueia → circuito protegido.
Bat− → MP1584 INPUT−
Fio preto. GND unificado.
MP1584 OUTPUT+ → polo (+) do capacitor 1000µF
Fio laranja. Perna mais longa = positivo. Filtra ruídos dos motores.
MP1584 OUTPUT− → polo (−) do capacitor → GND
Fio preto. Fecha o circuito do capacitor no GND.
Polo (+) do capacitor → ESP32 pino 5V0
Fio laranja. Use o pino 5V0 — último pino, lado esquerdo da placa.
GND unificado → ESP32 pino GND
Fio preto. Qualquer pino GND da placa.
Fluxo V2
Bat+ 24V→Diodo N04 → MP1584 IN+
Bat− GND→MP1584 IN− = GND
MP1584 OUT+ 5V→Cap (+) → ESP32 5V0
MP1584 Out− GND→Cap (−) → ESP32 GND
✅
Teste: LED do ESP32 acende. Voltímetro: 5V entre 5V0 e GND, 3.3V entre 3V3 e GND.

■ 5V0 — entrada 5V (lado esquerdo, base)

Passo 3 — Motor Esquerdo (Driver 1)

GPIO 12 (avança) e GPIO 14 (recua) controlam o motor esquerdo. Desligue a bateria antes de conectar.

ℹ️
Desligue a bateria antes de qualquer conexão. Religue só após verificar tudo.
Alimentação de potência — Driver 1 (24V)
Bat+ 24V → Driver 1 VM+ (borne parafuso, pino 11)
Fio vermelho GROSSO. Use fio ≥ 1,5mm².
GND unificado → Driver 1 VM− (borne parafuso, pino 12)
Fio preto GROSSO. Mesmo barramento de GND da bateria.
Lógica de controle — Driver 1 (header 8 pinos)
MP1584 OUT+ → Driver 1 VCC (pino 7)
Fio laranja. Ramal direto do MP1584, paralelo ao fio do ESP32 5V0.
ESP32 GND → Driver 1 GND (pino 8)
Fio preto. CRÍTICO: sem este fio o driver não recebe os sinais do ESP32.
ESP32 pino 3V3 → Driver 1 R_EN (pino 3)
Fio amarelo. Enable permanente do lado R.
ESP32 pino 3V3 → Driver 1 L_EN (pino 4)
Pode ramificar do mesmo fio do R_EN.
ESP32 GPIO 12 → Driver 1 R_PWM (pino 1)
Fio azul. Controla AVANÇAR. GPIO 12 fica no lado direito da placa.
ESP32 GPIO 14 → Driver 1 L_PWM (pino 2)
Fio verde. Controla RECUAR. GPIO 14 fica no lado direito da placa.
Motor Esquerdo → Driver 1
Motor Esq. Fio A → Driver 1 Motor+ (pino 10)
Inverter se girar ao contrário do esperado.
Motor Esq. Fio B → Driver 1 Motor− (pino 9)
💾 Teste Motor Esquerdo (SDK 3.0+)
// Teste Motor Esquerdo — Driver 1
// GPIO 12 = R_PWM (avança) | GPIO 14 = L_PWM (recua)
#define RPWM_1  12
#define LPWM_1  14

void setup() {
  ledcAttach(RPWM_1, 5000, 8); // 5 kHz, 8 bits
  ledcAttach(LPWM_1, 5000, 8);
  Serial.begin(115200);
}

void loop() {
  Serial.println("Avancando...");
  ledcWrite(RPWM_1, 150); ledcWrite(LPWM_1, 0);
  delay(2000);
  ledcWrite(RPWM_1, 0);   ledcWrite(LPWM_1, 0);
  delay(1000);
  Serial.println("Recuando...");
  ledcWrite(RPWM_1, 0);   ledcWrite(LPWM_1, 150);
  delay(2000);
  ledcWrite(RPWM_1, 0);   ledcWrite(LPWM_1, 0);
  delay(1000);
}

Passo 4 — Motor Direito (Driver 2)

GPIO 16 (avança) e GPIO 17 (recua). Mesma lógica do Driver 1.

⚠️
Não use GPIO 6–11 — ligados à flash interna, travará o ESP32. Use GPIO 16 e GPIO 17.
Alimentação de potência — Driver 2 (24V)
Bat+ 24V → Driver 2 VM+ (pino 11)
Pode ramificar do mesmo ponto do Driver 1.
GND unificado → Driver 2 VM− (pino 12)
Lógica de controle — Driver 2
MP1584 OUT+ → Driver 2 VCC (pino 7)
Fio laranja. Ramal direto do MP1584, mesmo ponto do fio do Driver 1 VCC.
ESP32 GND → Driver 2 GND (pino 8)
ESP32 pino 3V3 → Driver 2 R_EN (pino 3)
Pode ramificar do fio 3V3 do Driver 1.
ESP32 pino 3V3 → Driver 2 L_EN (pino 4)
ESP32 GPIO 16 → Driver 2 R_PWM (pino 1)
Fio roxo. Lado direito da placa, marcado "16".
ESP32 GPIO 17 → Driver 2 L_PWM (pino 2)
Fio ciano. Lado direito da placa, marcado "17".
Motor Direito → Driver 2
Motor Dir. Fio A → Driver 2 Motor+ (pino 10)
Inverter se girar ao contrário.
Motor Dir. Fio B → Driver 2 Motor− (pino 9)

#define RPWM_1 12  // Motor Esq — avança
#define LPWM_1 14  // Motor Esq — recua
#define RPWM_2 16  // Motor Dir — avança
#define LPWM_2 17  // Motor Dir — recua

void setup() {
  ledcAttach(RPWM_1, 5000, 8); ledcAttach(LPWM_1, 5000, 8);
  ledcAttach(RPWM_2, 5000, 8); ledcAttach(LPWM_2, 5000, 8);
  Serial.begin(115200);
}
void mover(int e, int d) {
  ledcWrite(RPWM_1, e > 0 ? e : 0); ledcWrite(LPWM_1, e < 0 ? -e : 0);
  ledcWrite(RPWM_2, d > 0 ? d : 0); ledcWrite(LPWM_2, d < 0 ? -d : 0);
}
void loop() {
  Serial.println("Ambos avancam");
  mover(150, 150); delay(2000); mover(0,0); delay(500);
  Serial.println("Ambos recuam");
  mover(-150,-150); delay(2000); mover(0,0); delay(500);
}

Passo 5 — Receptor FS-iA6B (Modo Rádio)

Conexão do receptor FS-iA6B ao ESP32 via protocolo iBUS. Opcional — só se for usar o rádio FS-i6X.

ℹ️
Este passo é opcional. Se for usar apenas o Xbox, pule para o Passo 6. O código já suporta os dois modos — o que conectar primeiro vira o controle ativo.
⚠️
Antes de conectar, configure o protocolo iBUS no FS-i6X: System → RX Setup → Protocol → iBUS. Sem isso o receptor não envia dados válidos.
Alimentação do FS-iA6B
ESP32 5V0 → FS-iA6B pino + (B/VCC)
Fio laranja. Use o conector B/VCC do receptor (canto direito).
ESP32 GND → FS-iA6B pino − (B/VCC)
Fio preto. GND comum.
Sinal iBUS
FS-iA6B porta i-BUS (SENS) → ESP32 GPIO 13
Fio roxo. Pino Signal da porta SENS do conector i-BUS. GPIO 13 = UART1 RX.
Mapeamento de canais (configurar no FS-i6X)
■ CH1 — Stick esq. horizontal → Virar (steering)
■ CH2 — Stick esq. vertical → Frente / Ré (throttle)
■ CH6 — Chave SwC ou SwD → Lâmina ON/OFF

ESP32 GND→FS-iA6B B/VCC pino −

#include <XboxSeriesXControllerESP32_asukiaaa.hpp>

// --- PINOS MOTORES TRAÇÃO (IBT-2 / BTS7960) ---
const int MOTOR_ESQ_RPWM = 12; // Motor Esq avança
const int MOTOR_ESQ_LPWM = 14; // Motor Esq recua
const int MOTOR_DIR_RPWM = 16; // Motor Dir avança
const int MOTOR_DIR_LPWM = 17; // Motor Dir recua

// --- PINO MOTOR DA LÂMINA (ROÇADEIRA) ---
const int MOTOR_LAMINA = 23; // Relé ou Driver On/Off

XboxSeriesXControllerESP32_asukiaaa::Core xboxController;
const int PWM_MAX = 220;
bool conectado_anteriormente = false;

void setup() {
  Serial.begin(115200);
  delay(1000);
  Serial.println("\n--- CONFIGURANDO SENTIDO: CIMA = FRENTE ---");

  // PWM com ESP32 Arduino SDK 3.0+ (ledcAttach substitui ledcSetup+ledcAttachPin)
  ledcAttach(MOTOR_ESQ_RPWM, 5000, 8);
  ledcAttach(MOTOR_ESQ_LPWM, 5000, 8);
  ledcAttach(MOTOR_DIR_RPWM, 5000, 8);
  ledcAttach(MOTOR_DIR_LPWM, 5000, 8);

  pinMode(MOTOR_LAMINA, OUTPUT);
  digitalWrite(MOTOR_LAMINA, LOW);

  xboxController.begin(); // Inicia busca BLE pelo controle Xbox
}

void loop() {
  xboxController.onLoop();

  if (xboxController.isConnected()) {
    if (!conectado_anteriormente) {
      Serial.println("\n[OK] CONECTADO!");
      conectado_anteriormente = true;
    }
    if (!xboxController.isWaitingForFirstNotification()) {
      // Analógico esquerdo — CIMA = POSITIVO (invertido)
      int32_t joyY = 32768 - (int32_t)xboxController.xboxNotif.joyLVert;
      int32_t joyX = (int32_t)xboxController.xboxNotif.joyLHori - 32768;

      // Deadzone: evita trepidação quando o analógico está em repouso
      if (abs(joyY) < 3500) joyY = 0;
      if (abs(joyX) < 3500) joyX = 0;

      // Tank Drive Mixer: combina Y e X para controle diferencial
      int alvo_esq = map(joyY + (joyX / 2), -32768, 32767, -PWM_MAX, PWM_MAX);
      int alvo_dir = map(joyY - (joyX / 2), -32768, 32767, -PWM_MAX, PWM_MAX);

      // Gatilho direito RT > metade = liga lâmina
      digitalWrite(MOTOR_LAMINA, xboxController.xboxNotif.trigRT > 512 ? HIGH : LOW);

      acionarMotores(alvo_esq, alvo_dir);

      // Telemetria a cada 500ms
      static unsigned long lastLog = 0;
      if (millis() - lastLog > 500) {
        Serial.print("JOY Y:"); Serial.print(joyY);
        Serial.print(" X:");   Serial.print(joyX);
        Serial.print(" | ESQ:"); Serial.print(alvo_esq > 0 ? "FRENTE " : "TRAS "); Serial.print(abs(alvo_esq));
        Serial.print(" | DIR:"); Serial.print(alvo_dir > 0 ? "FRENTE " : "TRAS "); Serial.print(abs(alvo_dir));
        Serial.print(" | LAMINA:"); Serial.println(digitalRead(MOTOR_LAMINA) ? "LIGADA" : "OFF");
        lastLog = millis();
      }
    }
  } else {
    if (conectado_anteriormente) {
      Serial.println("\n[!] CONEXAO PERDIDA - PARANDO");
      parar_motores();
      digitalWrite(MOTOR_LAMINA, LOW);
      conectado_anteriormente = false;
    }
    delay(500);
  }
}

void acionarMotores(int v_esq, int v_dir) {
  ledcWrite(MOTOR_ESQ_RPWM, v_esq >= 0 ? abs(v_esq) : 0);
  ledcWrite(MOTOR_ESQ_LPWM, v_esq < 0  ? abs(v_esq) : 0);
  ledcWrite(MOTOR_DIR_RPWM, v_dir >= 0 ? abs(v_dir) : 0);
  ledcWrite(MOTOR_DIR_LPWM, v_dir < 0  ? abs(v_dir) : 0);
}

void parar_motores() {
  ledcWrite(MOTOR_ESQ_RPWM, 0); ledcWrite(MOTOR_ESQ_LPWM, 0);
  ledcWrite(MOTOR_DIR_RPWM, 0); ledcWrite(MOTOR_DIR_LPWM, 0);
}
