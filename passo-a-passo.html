Passo 1 — Ligar apenas o ESP32

Monte a fonte 5V antes de conectar qualquer driver ou motor. Teste e valide antes de continuar.

V1 Versão Simples — conexão direta sem diodo nem capacitor
🚫
NÃO conecte a bateria de 24V diretamente ao ESP32 — vai queimá-lo. Use sempre o conversor buck MP1584 para reduzir para 5V.
⚠️
Ajuste o MP1584 primeiro, com voltímetro, sem o ESP32 conectado. Gire o trimpot até marcar exatamente 5.0V entre OUT+ e OUT−.
⚠️
Atenção na polaridade! Na V1, sem o diodo de proteção, se ligar a bateria ao contrário o circuito pode ser danificado. Sempre confira o positivo (+) e negativo (−) antes de energizar.
Lista de conexões V1 — Fonte 5V para o ESP32 (4 ligações)
Bateria 24V B+ → MP1584 INPUT+
Fio vermelho. Conecta diretamente o positivo da bateria à entrada do conversor buck. Confira a polaridade!
Bateria 24V B− → MP1584 INPUT−
Fio preto. Este é o ponto do GND unificado — todos os GNDs do sistema se unem aqui.
MP1584 OUTPUT+ → ESP32 pino VIN
Fio laranja. Saída do buck (já regulada em 5V) vai direto ao pino VIN do ESP32. NÃO use o pino "5V" como entrada — ele é saída.
MP1584 OUTPUT− → ESP32 pino GND
Fio preto. Feche o circuito conectando o negativo do buck ao GND do ESP32. Use qualquer pino GND da placa.
Fluxo de energia — V1 (Simples)
Bat+ 24V → MP1584 IN+ (direto)
Bat− GND → MP1584 IN− = GND unificado
MP1584 OUT+ (5V) → ESP32 VIN (direto)
MP1584 OUT− (GND) → ESP32 GND
✅
Teste de validação: Após ligar a bateria, o LED do ESP32 deve acender. Meça com voltímetro: 5V entre VIN e GND, 3.3V entre o pino 3V3 e GND. Se ok, vá para o passo 2.
V2 Versão Protegida — com diodo de proteção e capacitor de filtragem
🚫
NÃO conecte a bateria de 24V diretamente ao ESP32 — vai queimá-lo. A tensão máxima no pino VIN é 12V, no pino 5V é 5V. Use sempre o conversor buck MP1584.
⚠️
Ajuste o MP1584 primeiro, com voltímetro, sem o ESP32 conectado. Gire o trimpot até marcar exatamente 5.0V entre OUT+ e OUT−.
Lista de conexões V2 — Fonte 5V para o ESP32 (7 ligações)
Bateria 24V B+ → Diodo N04 (entrada, lado sem faixa — anodo)
Fio vermelho grosso. O lado sem marca/faixa do diodo é o anodo (entrada). A faixa cinza/prata é o catodo (saída).
Diodo N04 (saída, lado com faixa — catodo) → MP1584 INPUT+
Fio vermelho. Esta é a proteção contra polaridade invertida — se ligar a bateria ao contrário, o diodo bloqueia e protege o circuito.
Bateria 24V B− → MP1584 INPUT−
Fio preto. Este é o ponto do GND unificado — todos os GNDs do sistema se unem aqui.
MP1584 OUTPUT+ → polo (+) do capacitor 1000µF
Fio laranja. O polo positivo do capacitor tem a perna mais longa ou a marcação (+). Ele filtra ruídos dos motores e estabiliza a tensão.
MP1584 OUTPUT− → polo (−) do capacitor → GND unificado
Fio preto. Feche o circuito do capacitor e conecte ao barramento de GND.
Polo (+) do capacitor → ESP32 pino VIN
Fio laranja. No NodeMCU ESP-32S o pino VIN aceita 5V. NÃO use o pino marcado "5V" como entrada — ele é saída.
GND unificado → ESP32 pino GND
Fio preto. Use qualquer pino GND do ESP32. Este terra comum é fundamental para o sistema funcionar.
Fluxo de energia — V2 (Protegido)
Bat+ 24V → Diodo N04 → MP1584 IN+
Bat− GND → MP1584 IN− = GND unificado
MP1584 OUT+ (5V) → Cap 1000µF (+) → ESP32 VIN
MP1584 Out− (GND) → Cap 1000µF (−) → ESP32 GND
✅
Teste de validação: Após ligar a bateria, o LED do ESP32 deve acender. Meça com voltímetro: 5V entre VIN e GND, 3.3V entre o pino 3V3 e GND. Se ok, vá para o passo 2.
Pinos usados neste passo:
■ VIN — entrada 5V (lado direito, 1º pino superior)
■ GND — terra (múltiplos pinos, ambos os lados)
■ INPUT+ — entrada positiva (24V)
■ INPUT− — entrada negativa (GND)
■ OUTPUT+ — saída positiva (5V ajustado)
■ OUTPUT− — saída negativa (GND)
■ Trimpot — ajuste até 5.0V no multímetro

Passo 2 — Adicionar o Motor Esquerdo (Driver 1)

Com o ESP32 já funcionando, adicione o primeiro driver BTS7960 e um motor para testar o controle.

ℹ️
Desligue a bateria antes de fazer qualquer conexão nova. Só religue para testar após verificar todas as ligações do passo.
Alimentação de potência — Driver 1 (24V)
Bat+ 24V → Driver 1 VM+ (borne parafuso, pino 11)
Fio vermelho GROSSO. Fornece a potência de 24V para os motores. Use fio de pelo menos 1,5mm².
GND unificado → Driver 1 VM− (borne parafuso, pino 12)
Fio preto GROSSO. Terra da potência. Conecte ao mesmo barramento de GND da bateria.
Lógica de controle — Driver 1 (header 8 pinos)
ESP32 pino 5V → Driver 1 VCC (pino 7 do header)
Fio laranja fino. Alimenta o circuito lógico interno do BTS7960. Use o pino "5V" do ESP32 (é uma saída regulada).
ESP32 GND → Driver 1 GND (pino 8 do header)
Fio preto fino. CRÍTICO: sem este fio o driver ignora os sinais do ESP32.
ESP32 pino 3V3 → Driver 1 R_EN (pino 3 do header)
Fio amarelo. Habilita permanentemente o lado direito (R) do driver.
ESP32 pino 3V3 → Driver 1 L_EN (pino 4 do header)
Fio amarelo. Habilita permanentemente o lado esquerdo (L). Pode ramificar do mesmo fio do R_EN.
ESP32 GPIO 4 → Driver 1 R_PWM (pino 1 do header)
Fio azul. Controla a direção e velocidade para o sentido AVANÇAR.
ESP32 GPIO 5 → Driver 1 L_PWM (pino 2 do header)
Fio verde. Controla a direção e velocidade para o sentido RECUAR.
Motor Esquerdo → Driver 1 (bornes verdes)
Motor Esq. Fio A → Driver 1 Motor+ (borne parafuso, pino 10)
Qualquer fio do motor (inverter depois se girar ao contrário).
Motor Esq. Fio B → Driver 1 Motor− (borne parafuso, pino 9)
O segundo fio do motor. Se girar ao contrário do esperado, troque Motor+ com Motor−.
💾 Sketch de teste — Motor Esquerdo 
// Teste Motor Esquerdo — Driver 1
// GPIO 4 = R_PWM (avança) | GPIO 5 = L_PWM (recua)

#define RPWM_1  4
#define LPWM_1  5

void setup() {
  pinMode(RPWM_1, OUTPUT);
  pinMode(LPWM_1, OUTPUT);
  Serial.begin(115200);
  Serial.println("Iniciando teste Motor Esquerdo...");
}

void loop() {
  Serial.println("Avancando...");
  analogWrite(RPWM_1, 150);
  analogWrite(LPWM_1, 0);
  delay(2000);

  Serial.println("Parando...");
  analogWrite(RPWM_1, 0);
  analogWrite(LPWM_1, 0);
  delay(1000);

  Serial.println("Recuando...");
  analogWrite(RPWM_1, 0);
  analogWrite(LPWM_1, 150);
  delay(2000);

  Serial.println("Parando...");
  analogWrite(RPWM_1, 0);
  analogWrite(LPWM_1, 0);
  delay(1000);
}
✅
Resultado esperado: Motor avança 2s → para 1s → recua 2s → para 1s, em loop. Se girar ao contrário, troque os fios Motor+ e Motor− nos bornes do driver.
Header lógico (8 pinos, lado direito):
■ Pino 1 R_PWM → GPIO 4 (azul)
■ Pino 2 L_PWM → GPIO 5 (verde)
■ Pino 3 R_EN → 3.3V (amarelo)
■ Pino 4 L_EN → 3.3V (amarelo)
■ Pino 5/6 R_IS/L_IS → não usar
■ Pino 7 VCC → 5V ESP32
■ Pino 8 GND → GND ESP32

Bornes parafuso (lado esquerdo):
■ Pino 11 VM+ → Bat+ 24V
■ Pino 12 VM− → GND bateria
■ Pino 10 Motor+ → Fio A
■ Pino 9  Motor− → Fio B
Pinos usados neste passo:
■ 5V → VCC Driver 1 (pino 7)
■ GND → GND Driver 1 (pino 8)
■ 3V3 → R_EN + L_EN
■ GPIO 4 → R_PWM
■ GPIO 5 → L_PWM

Passo 3 — Adicionar o Motor Direito (Driver 2)

Repita o processo do Driver 1, mas usando GPIO 16 e GPIO 17 para o segundo driver.

⚠️
Não use GPIO 6 e GPIO 7 — estão ligados à memória flash interna e travarão o ESP32. Use GPIO 16 e GPIO 17.
Alimentação de potência — Driver 2 (24V)
Bat+ 24V → Driver 2 VM+ (borne parafuso, pino 11)
Fio vermelho grosso. Pode ramificar do mesmo ponto do Driver 1 na bateria.
GND unificado → Driver 2 VM− (borne parafuso, pino 12)
Fio preto grosso. Mesmo barramento de GND da bateria e Driver 1.
Lógica de controle — Driver 2 (header 8 pinos)
ESP32 pino 5V → Driver 2 VCC (pino 7 do header)
Fio laranja. Pode partir do mesmo pino 5V do ESP32.
ESP32 GND → Driver 2 GND (pino 8 do header)
Fio preto. Sem isso os sinais PWM não chegam corretamente ao driver.
ESP32 pino 3V3 → Driver 2 R_EN (pino 3 do header)
Fio amarelo. Pode ramificar do mesmo fio 3V3 que vai ao Driver 1.
ESP32 pino 3V3 → Driver 2 L_EN (pino 4 do header)
Fio amarelo. Pode ser o mesmo fio ramificado dos outros enables.
ESP32 GPIO 16 → Driver 2 R_PWM (pino 1 do header)
Fio roxo. GPIO 16 fica no lado direito da placa, marcado como "16". NÃO use GPIO 6.
ESP32 GPIO 17 → Driver 2 L_PWM (pino 2 do header)
Fio ciano. GPIO 17 fica no lado direito da placa, marcado como "17". NÃO use GPIO 7.
Motor Direito → Driver 2 (bornes verdes)
Motor Dir. Fio A → Driver 2 Motor+ (pino 10)
Qualquer fio do motor (inverter se girar ao contrário).
Motor Dir. Fio B → Driver 2 Motor− (pino 9)
O segundo fio do motor direito.
💾 Sketch de teste — Ambos os Motores 
// Teste dos 2 motores juntos
#define RPWM_1 4   // Motor Esq — avança
#define LPWM_1 5   // Motor Esq — recua
#define RPWM_2 16  // Motor Dir — avança
#define LPWM_2 17  // Motor Dir — recua

void setup() {
  pinMode(RPWM_1, OUTPUT); pinMode(LPWM_1, OUTPUT);
  pinMode(RPWM_2, OUTPUT); pinMode(LPWM_2, OUTPUT);
  Serial.begin(115200);
}

void mover(int velEsq, int velDir) {
  analogWrite(RPWM_1, velEsq > 0 ? velEsq : 0);
  analogWrite(LPWM_1, velEsq < 0 ? -velEsq : 0);
  analogWrite(RPWM_2, velDir > 0 ? velDir : 0);
  analogWrite(LPWM_2, velDir < 0 ? -velDir : 0);
}

void parar() { mover(0, 0); }

void loop() {
  Serial.println("Ambos avancam");
  mover(150, 150);  delay(2000);
  parar();          delay(500);

  Serial.println("Ambos recuam");
  mover(-150, -150); delay(2000);
  parar();           delay(500);
}
Driver 2 — mesmas posições do Driver 1:
■ Pino 1 R_PWM → GPIO 16 (roxo)
■ Pino 2 L_PWM → GPIO 17 (ciano)
■ Pino 3/4 EN → 3.3V
■ Pino 7 VCC → 5V
■ Pino 8 GND → GND
Pinos novos neste passo:
■ GPIO 16 → R_PWM Driver 2
■ GPIO 17 → L_PWM Driver 2

⚠ NÃO USE:
GPIO 6 (CLK flash), GPIO 7 (D0 flash)
GPIO 8–11 também são da flash interna

💾 Sketch completo — Sistema pronto para uso 
// Sistema completo — 2 Motores Dewert 24V via BTS7960
// ESP32S NodeMCU v1.1

#define RPWM_ESQ  4
#define LPWM_ESQ  5
#define RPWM_DIR 16
#define LPWM_DIR 17

void motorEsq(int vel) {
  if (vel > 0)      { analogWrite(RPWM_ESQ, vel); analogWrite(LPWM_ESQ, 0); }
  else if (vel < 0) { analogWrite(RPWM_ESQ, 0); analogWrite(LPWM_ESQ, -vel); }
  else               { analogWrite(RPWM_ESQ, 0); analogWrite(LPWM_ESQ, 0); }
}

void motorDir(int vel) {
  if (vel > 0)      { analogWrite(RPWM_DIR, vel); analogWrite(LPWM_DIR, 0); }
  else if (vel < 0) { analogWrite(RPWM_DIR, 0); analogWrite(LPWM_DIR, -vel); }
  else               { analogWrite(RPWM_DIR, 0); analogWrite(LPWM_DIR, 0); }
}

void setup() {
  pinMode(RPWM_ESQ, OUTPUT); pinMode(LPWM_ESQ, OUTPUT);
  pinMode(RPWM_DIR, OUTPUT); pinMode(LPWM_DIR, OUTPUT);
  Serial.begin(115200);
  Serial.println("Sistema pronto!");
}

void loop() {
  motorEsq(200);   // Motor esq avança (0-255)
  motorDir(200);   // Motor dir avança
  delay(3000);
  motorEsq(0);
  motorDir(0);
  delay(1000);
  motorEsq(-200);  // Recua
  motorDir(-200);
  delay(3000);
  motorEsq(0);
  motorDir(0);
  delay(1000);
}
